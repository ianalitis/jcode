# `cargo clippy --all-targets --all-features -- -D warnings` fails on clippy 1.98.x

Date: 2026-09-21. Observed on upstream `e589cbe5a` (v0.86.0) while resolving a
local fork's merge onto that commit. Status: filed upstream as
[#1348](https://github.com/1jehuang/jcode/issues/1348) and fixed locally; no PR
yet.

## Expected and observed

The quality job in `.github/workflows/ci.yml` runs:

```bash
cargo check --all-targets --all-features
cargo clippy --all-targets --all-features -- -D warnings
```

with `dtolnay/rust-toolchain@stable`. On current stable
(`rustc 1.98.1`, `clippy 0.1.98`, 2026-09-01) the clippy step fails on code that
is unchanged from upstream master. Twelve sites across six crates:

## Fixes applied locally

Mechanical, except for one case that needs judgment:

```rust
// jcode-base/src/voice.rs
- if data_len.is_some() || len == 0 || len % 2 != 0 {
+ if data_len.is_some() || len == 0 || !len.is_multiple_of(2) {

// jcode-base/src/voice/streaming_capture.rs (let-chains are available: edition 2024)
- if !matches!(event, NariEvent::Finished(_)) {
-     if let Ok(mut events) = e.lock() {
-         events.push(event);
-     }
- }
+ if !matches!(event, NariEvent::Finished(_))
+     && let Ok(mut events) = e.lock()
+ {
+     events.push(event);
+ }
```

`crates/jcode-app-core/src/tool/browser_fast.rs:109` must **not** take clippy's
suggestion. The code is:

```rust
Value::Array(items) => items
    .iter_mut()
    .fold(false, |found, item| redact_credentials(item) || found),
```

Clippy suggests `any(|item| redact_credentials(item))`, which short-circuits and
would stop redacting credentials in the remaining array items as soon as one
item reports a hit. The side effects are the point, so the local fix keeps full
traversal and only removes the short-circuit operator:

```rust
// `|` instead of `||`: every item must be visited so the redaction runs for each
// one; `any(..)` would stop at the first hit and skip the rest.
Value::Array(items) => items
    .iter_mut()
    .fold(false, |found, item| redact_credentials(item) | found),
```

`crates/jcode-base/src/side_panel.rs:268` has eight parameters. Restructuring it
is a judgment call for the maintainer; the local fix allows the lint at that one
site with a comment, matching existing precedent elsewhere in the tree.
