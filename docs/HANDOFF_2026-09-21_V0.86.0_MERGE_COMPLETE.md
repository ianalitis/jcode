### Two tooling lessons from this pass

- `cargo clippy --fix` is not safe for a lint sweep: rustfix also applies
  machine-applicable `dead_code` suggestions, which silently deletes items. One
  sweep removed a whole `#[cfg(test)] mod tests` block plus test helpers before it
  was caught in review. Apply fixes per lint, not blanket.
- After `git apply` in a fresh worktree, `touch` the touched files (or check
  `cargo test -- --list`) before trusting a run: cargo considered the first build
  up to date and silently ran a stale test binary, which reported zero matching
  tests for tests that existed on disk.
